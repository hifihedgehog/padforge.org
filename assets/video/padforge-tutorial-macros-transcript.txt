Here's how to make two macros in PadForge: a button chord that sends a shortcut, and a button that types a message. You're hearing a generated voice.

Open the controller, go to the Macros tab, and click Add.

Name it Task Manager.

Under Trigger, open Add from List, and pick Gamepad Left Shoulder. Open it again, and add Gamepad Right Shoulder. Holding both together is the chord.

Add an action, and make it a Key Press. In Key Combo, type Control, Shift and Escape, each in curly braces. That shortcut opens Task Manager.

Click Add again for a second macro. Name it Good Game, and give it Gamepad D-Pad Up.

Its action is a Text Block. Type the message here.

Press up on the pad, and PadForge types it out, letter by letter. Both macros save as you go.
